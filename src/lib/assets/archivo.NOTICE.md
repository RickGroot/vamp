# Archivo

`archivo-latin-var.woff2` is the **Archivo** variable font (latin subset; axes
`wght` 100–900 and `wdth` 62–125), the app's only interface typeface. It is used
at normal width for the UI and at its narrowest and heaviest for display type and
chord symbols.

- Designer: Omnibus-Type (Héctor Gatti and the Omnibus-Type team)
- License: **SIL Open Font License, Version 1.1** (OFL), free to use, bundle and
  redistribute with software.
- Source: Google Fonts (`fonts.gstatic.com`, Archivo v25, latin subset), self-hosted
  because the app works offline. Upstream: <https://github.com/Omnibus-Type/Archivo>

The full OFL text is available at <https://openfontlicense.org/>. This font is a
bundled asset, never sold on its own, in keeping with the OFL.
